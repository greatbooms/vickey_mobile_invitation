# 일러스트 다국어 청첩장

사용자가 승인한 시안: 아이보리 종이, 세이지 그린, 코랄 리본, 수채화 커플과 식물 장식. 실제 사진은 사용하지 않는다.

React + TypeScript + Vite 정적 사이트. 중국어 간체 기본, 영어·한국어 선택. URL의 lang 쿼리와 로컬 저장으로 선택 유지. 표지, 초대 문구, 커플 소개, 날짜·달력·카운트다운, 네 단계 식순, 장소·교통, 공유. 갤러리·계좌·업로드·DB 없음.

이름·날짜·장소는 명시적인 예시 값. 예식의 현지 시간은 Asia/Shanghai, 날짜 ISO 문자열에 +08:00 포함. 일정 저장은 Google 의존 없는 ICS 다운로드. 고덕 URI 링크 기본 제공, 주소 복사. 고덕 JS 키와 보안 설정 후 사용자가 요청할 때 로드하는 내장 지도. 실제 장소 좌표는 GCJ-02로 확인해야 함.

공유: 링크 복사, OS 공유(지원 브라우저), 위챗 내 우측 상단 메뉴 안내, 카카오 키 설정 후 SDK 공유. 키가 없거나 실패하면 정직한 안내와 링크 복사 제공. 위챗 맞춤 카드 서명 서버는 이번 범위 밖이며 README에 조건 기록.

폰트는 시스템 폰트, 일러스트는 로컬 파일. SDK는 필요 시에만 로드하고 실패해도 청첩장 본문 유지. Vercel 미리보기 지원; 중국 운영은 홍콩 리전 정적 호스팅 검토, 중국 현지 통신망 테스트 필요.

검증: 날짜 경계·달력·ICS·언어 처리 테스트, TypeScript/프로덕션 빌드, 모바일/데스크톱 브라우저 화면과 언어·공유 안내 확인.
